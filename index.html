A clearer view of the work.

Exponential OS is Aaron Bennett's private workspace for managing business activity, research and website performance. The application runs locally on his Windows computer. This website explains the application and its Google connection.

Read-only search reporting

The Search Console connection reads search performance for the selected, authorised website. It brings clicks, impressions, click-through rates, average search positions, searches and pages into the local dashboard, with scheduled updates and a manual refresh.

Google's read-only Search Console permission applies to the connected account's verified sites. The current integration imports only the selected AW Pressure Washing property.

Access stays private

This is a private operating tool, with no public registration. Visiting this information website does not provide access to the application or its records. Google access is granted by the account holder through Google's own consent screen.

How data is handled

Search reports are saved in the local operating system. Saved Google connection credentials are encrypted using the Windows account. The app does not ask for or store a Google password.

Read the privacy information and usage terms for details, including revoking Google access.
